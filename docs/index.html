Zero-trust

SROS2 enclaves, signed governance, topic ACLs, encrypted discovery, least-privilege publishers.

Edge AI

PyTorch CNN+ViT for segmentation, depth and spoof detection; ONNX / TensorRT FP16 & INT8 export for Jetson Orin.

Agentic RAG

LangGraph agents triage with a Qdrant knowledge base; LLM may only escalate severity, never downgrade rule-based critical.

Intrusion defense

Isolation Forest + autoencoder + hard rules + eBPF syscall audit; e-stop before analysis.

Post-quantum ready

Hybrid Ed25519 + CRYSTALS-Dilithium3 signing hook, signed certificate revocations.

Human in the loop

Operator override console; the AI can stop the robot but only a human can release it.
